# قطع غيار السيارات

واجهة متجر تجريبية مبنية باستخدام React وVite. تبدأ باختيار الشركة والنوع وسنة الصنع، ثم تعرض المنتجات المرتبطة بتركيبة السيارة المختارة.

## بيانات التوافق

بيانات المركبات والمنتجات في `src/mockFitments.js` وهمية للاختبار فقط، وتشمل سيارات Toyota Camry وCorolla وHyundai Elantra وSonata وNissan Altima وPatrol وFord Taurus وGMC Yukon ضمن سنوات حديثة. يربط كل سجل سيارة بمعرّفات المنتجات المسموح بعرضها، وتتحقق الواجهة عند بدء التشغيل من فرادة مسارات السيارات، وصحة معرّفات المنتجات، وعدم وجود منتجات غير مسندة أو تعارضات مع الشركة المحددة لبعض المنتجات.

هذه الروابط لا تثبت التوافق الميكانيكي الفعلي، ولا تصلح للبيع أو لتأكيد الطلب. قبل استخدام الكتالوج تجاريًا، استبدلها ببيانات موثقة من كتالوج قطع موثوق، مع التحقق من رقم الهيكل والفئة والمحرك.

## التشغيل والتحقق

```sh
npm install
npm run dev
npm run lint
npm run build
```
